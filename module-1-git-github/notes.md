## Key vocabulary (in your own words)

- repository: it's where you store your project or file and you can track using git.
- commit: it save the changes in your code
- branch: it's a separate version where you can make changes but doesn't affect the main branch.
- push / pull: push can send local changes to the github, while pull can send what's in the github to your local computer.
- pull request: it request to merge the changes from one branch to another branch.
- merge conflict: when two branches did a different changes at the same part of the code or file it can cause problem, because git doesn't determine what version is correct.
